My Experience Learning Web Development

As a Computer Science student at NAMI College, Web Development is one of the areas I am currently studying. Learning how websites work has been an interesting experience because it combines programming with creativity and design.

Starting With HTML

HTML was one of the first technologies I worked with when learning Web Development. At first, tags such as headings, paragraphs and links seemed simple. However, as I started creating complete pages, I understood the importance of organising information properly.

I learned about lists, tables, forms, links and semantic elements. These concepts helped me understand that HTML provides the structure of a website.

Moving to CSS

After learning the basics of HTML, I started working with CSS. CSS made it possible to change the appearance of my pages by adding colours, spacing, borders, typography and different layouts.

One of the things I found interesting was learning Flexbox and Grid. These tools made it easier to arrange content and create layouts that were more organised.

Learning JavaScript

JavaScript introduced me to interaction on websites. Instead of only displaying information, a webpage can respond when a user clicks a button, submits a form or interacts with another element.

I am still learning JavaScript, but working with simple events and DOM manipulation has helped me understand how client-side scripting works.

Responsive Design

Another important lesson has been responsive design. Websites are accessed using many different devices, so a page should not only look good on a desktop screen.

Using media queries and responsive layouts helped me understand how a webpage can adjust when the screen becomes smaller.

Challenges

As a student, one of the challenges I experience while learning Web Development is debugging. A small mistake in HTML, CSS or JavaScript can sometimes affect a large part of a webpage.

Testing the webpage, checking the browser developer tools and making changes step by step has helped me understand how to find and solve these problems.

What I Have Learned

The biggest lesson I have learned is that practical work is important. Reading about a programming concept gives me an understanding of the theory, but creating something myself makes the concept much clearer.

Conclusion

I am still at the learning stage of Web Development, and there are many technologies and concepts I want to explore in the future. Building this portfolio has allowed me to practise HTML, CSS and JavaScript while creating something that represents my current skills and learning journey.
