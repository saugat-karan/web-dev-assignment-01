WEB DEVELOPMENT COURSEWORK

Site Report

My experience developing this student portfolio.

Site Report Content

01

Introduction

This portfolio website was created as part of my learning experience in Web Development. I am a Computer Science student at NAMI College, and this project gave me an opportunity to apply the concepts I have been learning in class.

The website contains six connected pages: Home, Projects, Skills, Blog, Contact and Site Report. The main purpose of the portfolio is to introduce myself, present my coursework and demonstrate my understanding of basic web development technologies.

02

Learning HTML

HTML was used to create the basic structure of the portfolio. During the development process, I worked with headings, paragraphs, links, lists, tables, forms and different semantic HTML elements.

Using semantic elements such as header, nav, main, section, article and footer helped me understand how webpages can be organised logically. I also learned how links can connect different HTML pages together.

03

Learning CSS

CSS was used to style the portfolio and create its overall visual appearance. I worked with typography, spacing, borders, backgrounds, buttons, cards and different layouts.

I used Flexbox and CSS Grid to arrange different sections. The Projects page uses a different grid structure so that the projects do not all appear in exactly the same layout.

04

Design Decisions

I chose a simple and clean design because the main purpose of this website is to present my student work clearly. A dark blue colour is used as the main accent colour with white and light grey backgrounds.

I used a simple sans-serif font because it is easy to read. Cards are used to organise information on the Home page, while the Projects page uses a grid to display different projects.

I also kept the navigation consistent across all six pages so that users can easily move from one section of the portfolio to another.

05

Responsive Design

Responsive design was an important part of the development process. Websites need to work on different screen sizes, including desktop, tablet and mobile devices.

I used CSS media queries to change the layout when the screen becomes smaller. The navigation changes into a mobile menu, project cards become single-column layouts and other sections adjust their spacing.

06

JavaScript

JavaScript was used to add basic interaction to the website. The mobile navigation menu uses JavaScript to open and close the navigation links.

JavaScript is also used on the contact form to check that required fields have been completed before the email action is started.

07

Challenges I Faced

One of the challenges I faced while developing the portfolio was maintaining a consistent design across all six pages. Since the pages contain different types of information, I had to make sure they still looked like parts of the same website.

Responsive design was another challenge. Some layouts that looked good on a large screen became crowded on a smaller screen. I solved this by using CSS media queries and testing the website at different screen sizes.

Debugging was also part of the learning process. When something did not work, I checked the HTML structure, CSS rules and JavaScript code to find the problem.

08

What I Learned

This project helped me understand that creating a website involves more than writing individual pieces of HTML or CSS. All the pages need to work together, and the navigation, layout and styling need to remain consistent.

I also learned that practical work is important when studying Web Development. Reading about HTML, CSS and JavaScript is useful, but creating a real website makes it easier to understand how the different technologies work together.

09

Reflection

As a Computer Science student, this project has given me useful practical experience with web technologies. I am still learning and developing my skills, so there are many areas I would like to improve.

In the future, I would like to improve the visual design, learn more advanced JavaScript, add better form functionality and create more complex projects. I would also like to learn additional technologies that can be used to build modern websites and applications.
